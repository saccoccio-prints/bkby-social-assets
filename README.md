# BeeKindBeeYourself - social images

Public image host for [BeeKindBeeYourself](https://www.etsy.com/shop/BeeKindBeeYourself) social posts.

**Images only.** Every file here is a marketing image already published, or about to be, on Instagram or Facebook. It lives here because Metricool schedules images by public URL and the project's working repository is private.

Nothing else belongs in this repository - no copy, no specs, no notes, no data. Files are added by `social_assets.py`, which refuses anything that is not a real JPEG or PNG.

Layout mirrors `social/posts/<date>/<batch>/`.
